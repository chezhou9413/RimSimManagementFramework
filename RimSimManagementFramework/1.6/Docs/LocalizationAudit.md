# 框架界面翻译审计

日期：2026-09-25。范围：`RimSimManagementFramework`，不包含同级餐厅扩展。

## 结果

- 扫描 373 个 C# 源文件。
- 新增 169 个中英文成对翻译键，包含补齐已有调用缺失的“页面”按钮和免费服务评价提示键。
- 补齐教程语言条目 19 条：中文 16 条、英文 3 条。货柜教程的 `StorageManagement` 引用与原有英文 `Storage` 键不一致，已补齐实际引用并保留既有键。
- 翻译调用总数从 1609 处增加至 1817 处，净增加 208 处。该数字是调用位置数，不等于独立译文数量。
- 57 处已提供完整中英文键的界面调用移除中文或英文后备字面量，直接使用翻译键。
- 中英文 `Keyed` 合并后均为 1683 个键；明确引用的 1556 个键均存在，键集合、参数、重复键和 XML 检查通过。

## 保留项与统计边界

启发式扫描的中文候选行从 1034 行降至 803 行。剩余候选分类如下；一行可能含多个字符串，这不是译文条目数。

| 分类 | 行数 | 处理说明 |
| --- | ---: | --- |
| 内部状态或间接显示候选 | 255 | 包含行程推进、结账流程、租约变动等内部原因；后续新增直接展示时应在展示边界处理 |
| 开发者诊断或日志 | 243 | 保留诊断内容、日志标识和开发者操作菜单文字，便于现有排查流程使用 |
| 已有键的后备文本 | 63 | 保留加载阶段、模型和无键扩展配置等调用；这些文字已有键，不属于缺键界面 |
| 模型提示或评价内容 | 238 | 包括提示词、语义判定词、评价快照和生成内容；直接替换会影响评分和解析 |
| 界面文件中的候选 | 2 | 一个是重建队列的内部原因，一个是多行日志的标签；不是界面控件文字 |
| 文本解析或数据匹配 | 2 | 保留旧文本解析使用的中文分隔符 |

正常窗口、按钮、搜索、悬停说明、库存状态及本次审查的失败消息已接入翻译键。历史评价、玩家自定义文字、调试报告原文和模型上下文不承诺随切换语言重写。英文 `ID`、Def 标识和技术路径也不作为自然语言标签翻译。

## 布局与验证

搜索栏按译文宽度分配空间；按钮及页签超长时省略并显示完整提示；页面管理摘要避免长译文溢出；补货卡片按多行译文测量高度，列表绘制与高度计算复用同一文本函数。品质货柜检查文字缓存感知当前语言。

框架与餐厅依赖工程编译通过。仅执行静态语言检查和编译，没有启动游戏或部署。

维护方法与扩展作者示例见 [多语言接入说明](LocalizationGuide.md)。
