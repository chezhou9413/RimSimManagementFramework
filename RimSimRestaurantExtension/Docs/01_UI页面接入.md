# 餐厅 UI 页面接入

餐厅通过 `ShopUiPageDef` 向框架注册全店总览和单店菜单页，视觉使用 `ShopUiVisualUtility` 的标题、指标分区、提示条、搜索、表头、列表行、按钮与状态标签。公共布局组件位于框架 `Api/ShopUiVisualUtility.Layout.cs`，核心和扩展均可使用，不引用框架内部窗口的私有样式。

单店页面使用框架 `ShopManagerUiContext.SearchText` 搜索，菜单合并厨房制作与柜中现货，在单一滚动表格中显示菜名、倍率后的每份售价、份数范围、启用状态和制作情况。编辑窗口可修改名称、产物、基础价格、份数与每份原料；原料候选来自生产配方过滤器，确认时检查整组原料能否满足同一个配方。

菜单编辑与参数编辑只回写父窗口草稿，点击框架统一保存才应用。运行参数包括餐厅开关、价格倍率、顾客偏好及影响强度、等待接单与等待上菜两个期限，以及后厨储存区绑定、最多接单次数和追加间隔。堂食固定要求桌椅。

共享 Def Worker 不保存可变编辑状态。窗口通过 `ShopUiContext.GetOrCreatePageState<T>` 和 `GetPageState<T>` 保存、查询页面草稿；切页保留，窗口关闭时 `ClearContext` 清除全部页面状态。餐厅总览的页签、分页和滚动同样属于窗口。

总览统计先使用完整留存会话及子订单，再搜索分页。摘要展示餐厅数量、进行中用餐、待收款与已收款；待收款扣除已经支付的部分，已收款按付款回调归属到各子订单。列表默认展示进行中的用餐，勾选“包含历史记录”可查看结束记录。普通堂食和传送带自助拥有明确的方式标签，自助餐品来源显示为传送带。

布局使用实际字体行高和文字宽度，正文在标题与底部按钮之间滚动；绘制退出时恢复字体、对齐、换行和 GUI 颜色。
窗口按可用屏幕尺寸限制初始大小；窄窗口使用保留最小列宽的横向滚动表格，较矮窗口使用紧凑指标，长名称提供完整悬浮提示。参数表按经营与定价、用餐与等待、后厨货源分组，等待与追加间隔使用秒作为显示单位。
柜中现货保留来源柜与价格，通过货柜管理编辑。冰箱与商品柜窗口使用独立草稿，保存筛选、目标、阈值和销售规则，关闭丢弃；管理表同时展示实物现存、已预留及补货途中数量。

传送带配置可从建筑按钮或商店管理的餐厅菜单页“传送带管理”进入，使用同一套框架视觉组件。状态摘要展示现存、补餐在途、目标与损耗；上架表显示图标、食品与货源、每盘件数、目标盘数、单件售价和库存。目标超出容量时突出提示并禁用保存。在途统计只包含补餐，不把清理任务算作补餐。

2026-09-14 的界面整理仅执行框架与餐厅扩展编译、源码布局与差异检查，未启动游戏、未运行界面测试、未部署。实际视觉与游戏内 UI 缩放表现留待验收。
