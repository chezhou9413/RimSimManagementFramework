# 调试餐厅样板店

开发者菜单的样板店生成器准备扩展桌椅、双人卡座、拼接吧台、四种货柜、燃料灶、接待与出餐台、收银台和框架经营设施。冰箱连接木材发电机；壁挂柜放在内侧墙前。

生成器建立独立原版后厨储存区并绑定到本店，配置真实食材、冰箱库存目标和阈值。酒柜配置原版啤酒、库存目标、售价及现场饮用方式，放入少量实物，并在后厨提供补货货源。

后厨空地在全部家具生成后统一规划，排除所有建筑占用格与设施交互格。食材投放与原版储存区采用同一份格位清单，壁挂柜所在格保持属于商店。

员工包含厨师、服务员、框架补货员与收银员。默认等待接单和等待上菜各 12000 Tick，最多接单 3 次，追加间隔 1200 Tick。

“强制刷新顾客（当前地图）”会在当前地图的开放商店中选择符合条件的商店，跳过顾客出现时段、天气与随机概率，仍检查营业状态、客群匹配、人数上限和声望。餐厅的菜单、实物、岗位和路线也必须可用。手动刷新会立即重算餐厅经营快照，失败时显示具体阻塞原因。

如果样板店生成中断，后续员工分配和营业设置可能尚未执行。更新程序集并重启游戏后，可在没有其他区划的空地重新生成；已经中断的样板店不会自动补齐。

生成器会清理玩家指定的建店区域，是由玩家主动执行的开发者功能。验证只执行编译和静态核查，没有启动游戏或运行生成器。程序集按用户部署要求复制到 Steam 游戏的 Mods 目录。
