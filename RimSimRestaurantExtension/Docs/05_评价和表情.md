# 菜品气泡与评价

接单成功时调用框架公开入口 `SimShopUiApi.ShowCustomerThingBubble(customer, mealDef)`，转调既有 `ShopBubbleUtility.ShowThingBubble`。

气泡复用现有顾客头顶图标动画，显示实际点到的餐品，不依赖随机表情事件的触发概率。当前实现显示图标，菜名、份数与价格由餐厅 UI 展示，柜中现货同样弹出实际商品。每张子订单独立保存 `dishBubbleShown`，读档或恢复不重复弹出。

`RestaurantReviewSnapshotWorker` 汇总同一会话的所有子订单，补充商品、偏好、等待、交付、用餐与付款信息。用餐完成和付款完成分开记录，结账失败时保留未付款原因，不把已经吃完但尚未付款的订单描述成已完成交易。
