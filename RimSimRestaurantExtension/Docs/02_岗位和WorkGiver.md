# 餐厅岗位与任务

厨师与服务员由框架 `ShopStaffRoleDef` 分配，工作类型为 `Sim_ServiceWork`。收银员沿用框架收银岗位，补货人员沿用框架补货岗位，从商店区域内的储存架搬运。

| 工作 | 优先级 | 任务 |
|---|---:|---|
| 厨师恢复出餐运输 | 93 | 搬运已存在餐品到出餐台，不重新制作 |
| 厨师制作 | 92 | 使用冰箱优先与店内储存架货源，预留整单实际原料、搬运、烹饪并送到出餐台 |
| 服务员配送 | 91 | 从出餐台取餐或从来源柜提取现货，到本人托盘交付 90 Tick |
| 服务员接待 | 90 | 到原座顾客旁交谈 120 Tick 并确认菜单 |
| 厨师、服务员值班 | 8、7 | 到岗后继续原地值班，每 120 Tick 重查岗位工作 |

岗位分别绑定相关 WorkGiver 和 JobDef。服务员取餐和接单分开派工，保证送成品优先；查询先过滤完整取送路线，再按时间选单。出餐台允许多人预约访问，各订单的状态认领仍是互斥的。

员工中断时释放认领。交谈未完成回到等待接单，未出餐的烹饪释放食材预留并回到待制作，已经生成成品时保留运输阶段。中断餐品独立落地并暂时禁止普通取用，后续厨师或服务员回收同一件实物。

值班预约独立站位并避让建筑主体，不因员工已经到岗而跳过工作。撤销岗位、关闭营业且没有待收尾订单、禁用餐厅或移出区域会结束值班。基础生存需求、征召和玩家命令仍可打断；作息表和原版工作类型优先级仍然生效。
