# 家具餐位与桌面商品

堂食要求同店座位正交相邻具备 `SurfaceType.Eat` 的桌面。餐桌、吧台沿用原版桌面属性；餐椅、高脚椅及卡座沿用可坐属性。原版桌椅同样可用。

双人卡座占地 2×1，并设置 `multiSittable`。系统逐格查找和预约餐位，两名顾客各自持有一个格位与一只桌面托盘。顾客、服务员均避让其他活跃会话的餐位。

服务员在同店可达且可预约的桌边位置交談和交付。商品进入本人托盘，不落在地上；顾客保持原座，按送达顺序取到手中吃喝或收下商品。托盘是不提供建造入口的内部实体，负责保存真实商品并在对应桌沿绘制。

全部追加订单结束后才释放餐位。桌椅或托盘丢失时终止会话并释放现存实物；满座不创建候位队列。接待与出餐台供员工交接成品，顾客不前往该建筑点菜。

吧台按 1×1 建筑拼接，只连接同 Def 的吧台；绘制使用完整图集，建造图标使用独立图标。壁挂柜的逻辑位置位于墙前可通行格，旋转方向指向支撑墙，图像面向柜前；补货及取货发生在柜前格，失去支撑墙时按原版依附机制处理并释放库存。
